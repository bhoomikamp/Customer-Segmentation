# Customer Segmentation

## Overview
Segmented 3,900 U.S. retail customers into 3 behavioural clusters using 
K-Means clustering to derive targeted marketing campaign strategies.

## Tools Used
Python · MySQL · Orange Data Mining · Power BI · Excel

## Key Findings
- **C1 — Organic Buyers (57%)**: Full-price buyers, mixed gender, peak in Fall
- **C2 — Deal Seekers (16%)**: Price-sensitive males, always use discounts/promos
- **C3 — Loyal Members (27%)**: Subscribed males, highest engagement and loyalty

## Project Structure
- `data/` — Raw dataset (shopping_table.csv)
- `orange/` — K-Means clustering workflow (.ows)
- `report/` — Analytics insights report (.docx)
- `presentation/` — Final presentation (.pptx)
- `dashboard/` — Power BI dashboard screenshots
